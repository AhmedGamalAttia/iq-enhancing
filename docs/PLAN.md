# مشروع تنمية القدرات المعرفية — خطة المنتج والتنفيذ

> **الاسم المبدئي:** IQ-Enhancing (اسم مؤقت — يُفضّل تغييره لاحقاً لاسم لا يَعِد بـ "IQ" مباشرة، مثل *Cognita* / *Mindforge* / *Neura*).
> **الوصف:** منصة ويب (ثم PWA) لتنمية القدرات المعرفية والمهارات الذهنية بطرق علمية ممنهجة ومُجرَّبة — لا لعبة ولا تسلية.
> **آخر تحديث:** 2026-09-10

---

## 1) الرؤية والموقع في السوق

نبني منصة **جادة وقائمة على الأدلة العلمية** لتطوير القدرات المعرفية عند البشر بمختلف أعمارهم ومستوياتهم التعليمية. نبدأ بـ **تقييم تشخيصي** لتحديد نقاط القوة والضعف، ثم نقدّم **مسار تطوير مخصّص** يعتمد على تقنيات تعلُّم مثبتة علمياً.

**التمايز عن المنافسين (Lumosity, Elevate, Peak…):**
- هم يبيعون "ألعاب تدريب مخ" تعاني من **مشكلة عدم انتقال الأثر (Transfer Problem)**.
- نحن نركّز على **تحسين التعلُّم والتفكير في مجالات حقيقية** + مهارات معرفية أساسية، بمنهجية شفّافة ومصادر علمية معلنة.

### مبدأ المصداقية (حاسم)
- **لا نسمّيه "اختبار ذكاء / IQ".** اختبارات الذكاء المعيارية (Raven, WAIS…) محمية بحقوق ملكية ومُعايَرة إحصائياً على آلاف الأشخاص.
- نسمّيه **"تقييم تشخيصي للمهارات المعرفية" (Cognitive Skills Diagnostic)** ونصمّم بنوداً **أصلية** مستوحاة من الأنماط المعروفة.
- نعلن حدود الأداة بوضوح، ونتركها قابلة للتطوّر نحو معايرة إحصائية حقيقية عند التوسّع.

## 2) الأساس العلمي

ما **يعمل فعلاً** (مدعوم بأدلة قوية) وسنبني عليه:

| التقنية | الفكرة | التطبيق عندنا |
|---------|--------|----------------|
| **التكرار المتباعد (Spaced Repetition)** | مراجعة المعلومة قبيل نسيانها | خوارزمية **FSRS** لجدولة المراجعات |
| **الاسترجاع النشط (Active Recall)** | الاختبار الذاتي بدل القراءة السلبية | كل تدريب سؤال يتطلّب استرجاعاً |
| **الممارسة المتعمّدة (Deliberate Practice)** | تمرين مركّز على نقاط الضعف | المسار يوجّه المستخدم لأضعف محاوره |
| **التداخل (Interleaving)** | خلط أنواع المسائل | جلسات تدريب متعددة المحاور |
| **ما وراء المعرفة (Metacognition)** | تعلُّم كيفية التعلُّم | تقارير + تأمّل بعد كل جلسة |
| **العوامل الجسدية** | النوم/الرياضة/التغذية تؤثر على الأداء | تتبُّع اختياري وربطه بالأداء (مرحلة لاحقة) |

**تحذير علمي مُضمَّن في المنتج:** نُبلغ المستخدم أن تحسين مهارة محددة لا يعني بالضرورة رفع "الذكاء العام"، وأن القيمة الحقيقية في التعلُّم الأسرع والتفكير الأوضح.

## 3) المحاور المعرفية (Cognitive Dimensions)

نقيس ونطوّر عبر خمسة محاور:

1. **الذاكرة العاملة** (Working Memory) — تسلسلات، n-back مبسّط، استرجاع الأنماط.
2. **الاستدلال المنطقي** (Logical Reasoning) — استنتاج، متتاليات، شروط.
3. **التفكير الكمّي/العددي** (Numeracy & Quantitative) — أنماط عددية، نِسَب، تقدير.
4. **الاستدلال اللفظي والفهم** (Verbal Reasoning) — تناظر لفظي، فهم مقروء، مفردات.
5. **التفكير النقدي** (Critical Thinking) — كشف المغالطات، التفكير الاحتمالي، تقييم الأدلة.

كل محور: مستويات صعوبة (1–5)، بنوك أسئلة، ومقياس إتقان (mastery %).

## 4) نطاق الـ MVP (النسخة الأولى القابلة للإطلاق)

**نبدأ بشريحة رفيعة نُنجزها بإتقان، ثم نوسّع.**

- [ ] تسجيل دخول/حساب (Supabase Auth — email + OAuth).
- [ ] **تقييم تشخيصي تكيّفي** لمحور أو محورين (تزيد صعوبة السؤال مع الإجابات الصحيحة).
- [ ] **لوحة نتائج** توضّح مستوى كل محور ونقاط القوة/الضعف.
- [ ] **مسار تطوير** يقترح تدريبات حسب الضعف.
- [ ] **حلقة تدريب أساسية** بالتكرار المتباعد (FSRS) + الاسترجاع النشط.
- [ ] **تتبُّع التقدّم** (streak، نسبة الإتقان، رسم بياني للتطوّر).
- [ ] PWA (قابل للتثبيت + يعمل offline جزئياً).

المرحلة 2: باقي المحاور + طبقة الـ AI للتخصيص وتوليد الأسئلة + تقارير أعمق.
المرحلة 3: تطبيق موبايل مخصّص (لو لزم) + معايرة إحصائية + محتوى مجتمعي + B2B.

## 5) المعمارية التقنية (كلها مجانية في البداية)

| الطبقة | الأداة | التكلفة |
|--------|--------|---------|
| الاستضافة | **Vercel** (Hobby) — Root Directory = `web` | مجاني |
| الإطار | **Next.js 15** (App Router, TypeScript, Tailwind) | مجاني |
| قاعدة البيانات + Auth + Storage | **Supabase** (Free tier، 500MB) | مجاني |
| التكرار المتباعد | **ts-fsrs** (FSRS، مفتوح المصدر) | مجاني |
| PWA | **Serwist** / next-pwa | مجاني |
| الذكاء الاصطناعي | **Adapter** يبدأ بـ Gemini/Groq المجاني ← Claude API لاحقاً | مجاني مبدئياً |
| الرسوم البيانية | Recharts / تصميم مخصّص | مجاني |

### استراتيجية الـ AI (نقطة التكلفة الوحيدة)
- **طبقة تجريد (Provider Adapter):** واجهة واحدة `AIProvider` ونطبّقها لكل مزوّد.
- **البداية:** `GeminiProvider` (free tier سخي وجودة عالية) و/أو `GroqProvider` (سريع).
- **لاحقاً:** `AnthropicProvider` (Claude API) عند توفّر التمويل — **بدون إعادة كتابة أي منطق**، فقط تغيير متغيّر بيئة.
- **مبدئياً بدون AI:** المحتوى الأساسي (بنوك الأسئلة والشروحات) مكتوب يدوياً → صفر تكلفة، ثم نضيف الـ AI للتوليد والتخصيص والشرح التفاعلي.

## 6) نموذج البيانات (Postgres / Supabase)

```
profiles            (id ↔ auth.users, display_name, locale, created_at)
skills              (id, key, name_ar, name_en, description)
questions           (id, skill_id, difficulty 1-5, type, stem, choices[], answer, explanation)
diagnostic_sessions (id, user_id, status, started_at, finished_at)
diagnostic_items    (id, session_id, question_id, response, is_correct, ms_taken)
skill_levels        (user_id, skill_id, ability_estimate, mastery, updated_at)
review_cards        (id, user_id, question_id, fsrs_state jsonb, due_at)  -- حالة FSRS
review_logs         (id, card_id, rating, reviewed_at)
```

مع **Row Level Security (RLS)**: كل مستخدم يرى بياناته فقط.

## 7) منطق التقييم التكيّفي (مبسّط للـ MVP)

- نبدأ بصعوبة متوسطة (3).
- إجابة صحيحة → صعوبة +1 (بحد أقصى 5)، خاطئة → −1 (بحد أدنى 1).
- بعد N بنود لكل محور، نُقدّر القدرة كمتوسط مرجّح بالصعوبة والزمن.
- لاحقاً: نموذج **IRT** (Item Response Theory) لتقدير أدق (مرحلة معايرة).

## 8) خارطة الطريق (Roadmap)

- **المرحلة 0 — Scaffold:** إعداد المشروع، الـ schema، الـ AI adapter، صفحة هبوط. ✅
- **المرحلة 1 — MVP:** Auth + تشخيص محور/محورين + نتائج + حلقة تكرار متباعد + PWA.
- **المرحلة 2 — التوسّع:** 5 محاور كاملة + AI للتخصيص والتوليد + تقارير متقدمة + تحليلات.
- **المرحلة 3 — النضج:** موبايل native (إن لزم) + معايرة IRT + B2B (مدارس/شركات) + مجتمع.

---

## 9) نموذج الربح (لاحقاً)

- **Freemium:** أساسيات مجانية + اشتراك شهري (AI، تقارير عميقة، محتوى موسّع).
- **B2B:** تراخيص للمدارس/الجامعات/شركات التدريب.
- **شراكات:** مع مختصّين في علم النفس المعرفي والتعليم لإضفاء مصداقية ومحتوى.

---

## 10) الأخلاقيات والمخاطر

- **عدم المبالغة في الوعود** (تجنّب مصير Lumosity القانوني).
- **الخصوصية:** بيانات الأداء حسّاسة → RLS + شفافية + عدم بيع البيانات.
- **الشمول:** دعم العربية والإنجليزية، وإتاحة (a11y) للجميع.
- **التحيّز:** مراجعة البنود لتجنّب التحيّز الثقافي/اللغوي.
